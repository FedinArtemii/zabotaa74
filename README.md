# Забота 74 — WordPress и демонстрация для GitHub Pages

Новый сайт частного пансионата «Забота» в Копейске. Визуальное направление — Veloura: тёплый винный фон, крупная типографика и спокойная редакционная композиция.

**Демонстрация:** https://fedinartemii.github.io/zabotaa74/

## Что находится в репозитории

- `theme/zabota74/` — устанавливаемая тема WordPress с Gutenberg, адаптивными стилями, локальными шрифтами и графическими заглушками.
- `tools/seed.php` — создание страниц и семи материалов архива в обычном редакторе блоков.
- `tools/setup.mjs` — воспроизводимая локальная установка WordPress с SQLite.
- `docs/` — статический экспорт именно локального WordPress для GitHub Pages.
- `.github/workflows/pages.yml` — проверка и автоматическая публикация экспорта при push в main.
- `content/SOURCES.md` — источники, принятые редакционные решения и расхождения оригинального сайта.

GitHub Pages обслуживает HTML, CSS и JavaScript. PHP, база данных и админка WordPress работают локально или на WordPress-хостинге.

## Локальный запуск на Windows

Требуются Node.js 22+, PHP 8.1+ с `pdo_sqlite`, `sqlite3`, `mbstring`, `openssl`, `fileinfo`. В исходном окружении PHP расположен в `C:/php`. Другой путь задайте через `PHP_BIN`, а путь расширений — в `.local/php.ini`.

```powershell
npm run setup
npm start
```

Сайт: http://127.0.0.1:8074/

Админка: http://127.0.0.1:8074/wp-admin/

Случайные данные локального администратора записаны в `.local/admin-credentials.txt`. Они не входят в Git и не публикуются. Воспроизводимая установка загружает актуальный WordPress и официальный SQLite Database Integration. В этой сборке установлен WordPress 7.1.4.

`npm run setup` повторно импортирует исходное наполнение и может заменить редакторские изменения. После редактирования через админку повторно запускайте только `npm run export`, чтобы сохранить свои изменения.

## Редактирование и экспорт

В админке откройте **Страницы** или **Записи**. Основной контент хранится в зарегистрированных блоках Gutenberg. Сложные элементы галереи и расписания — блоки «Произвольный HTML», редактируемые в том же редакторе. Меню и общие контакты находятся в файлах темы.

При работающем локальном WordPress:

```powershell
npm run export
npm run verify
git add docs theme tools content README.md package.json .github .gitignore
git commit -m "Update website presentation"
git push origin main
```

Экспорт обходит страницы WordPress, заменяет локальные ссылки на `/zabotaa74/`, копирует шрифты и изображения. Секреты, база и админка в `docs` не попадают. Для другого имени Pages передайте переменную `PAGES_BASE`.

## Установка темы на рабочий WordPress

Скопируйте `theme/zabota74` в `wp-content/themes`, активируйте «Забота 74». При наличии WP-CLI импортируйте исходное содержание:

```text
wp eval-file /absolute/path/to/tools/seed.php
```

Главная, маршруты и настройки устанавливаются автоматически. На рабочем сервере можно использовать стандартную MySQL/MariaDB, SQLite нужен только для удобной локальной демонстрации. Внешних платных тем и конструкторов нет.

Перед рабочим запуском замените заглушки, согласуйте тексты и контакты, подключите реальную обработку заявок. Для индексации удалите принудительный `noindex` в `functions.php` и включите индексацию в настройках WordPress. На Pages демонстрация остаётся `noindex`.

## Проверки

`npm run verify` проверяет все экспортированные страницы, внутренние ссылки и ресурсы, русский язык документа, заголовки, альтернативные подписи, наличие шрифтов, синтаксис PHP и отсутствие локальных путей. Интерактивность и адаптивность проверяются в браузере.
